# Digital Geoff

> Virtual Chief of Staff + Solution/Data Architect Partner

An AI agent configuration for a high-performing virtual assistant designed to help with:
- Architecture and consulting delivery
- Stakeholder management
- Strategic planning and execution
- Day-to-day operational excellence

## What This Is

This repository contains the system configuration for **Digital Geoff** — an AI agent that operates as a tool-using assistant capable of:

- Planning work and executing tasks via connected tools (MCP servers, APIs)
- Producing human-quality deliverables (proposals, architecture docs, code)
- Managing projects across Asana, calendars, and documentation
- Supporting engineering work with Claude Code capabilities

## Files

| File | Purpose |
|------|---------|
| `DIGITAL_GEOFF_SYSTEM.md` | Full system prompt and operational configuration |

## Getting Started

Digital Geoff requires onboarding inputs to become operational:

1. Current projects (name, status, priority)
2. Tools in daily use (Asana, Gmail, GCal, Slack, etc.)
3. This week's meetings and deadlines
4. Tasks that are currently stuck or messy

Once configured, Digital Geoff will generate:
- Your priority stack
- Daily operating plan
- Top 5 automation recommendations
